## 📦 Installation

Download `StockMetaAI_Setup_2.x.x.exe` and run the installer.

**Requirements:**
- Windows 10/11 (64-bit)
- Internet connection for API calls
- [Google Gemini API key](https://aistudio.google.com/apikey) (free tier available)

---

## 🔧 Supported Formats

- **Images:** PNG, JPG, JPEG, WEBP, GIF, BMP
- **Vector:** EPS (new!)

---

## 📝 Getting Started

1. Install and launch StockMeta AI
2. Enter your Gemini API key in Settings
3. Select a folder containing your stock images/vectors
4. Choose platforms (Adobe Stock, Shutterstock, Freepik)
5. Click Generate and export your metadata CSVs
